# MERN lab phase

This is final project from GOMYCODE javascript fullstack developer course

This is a recipe search application based on food ingredients,  
e.g. `beef`, `chicken`, `potato`, `garlic`.

⚠️ You **cannot search by food name directly**, such as `pasta`, `burger`, or `fried rice`.
Please use **ingredient keywords** instead.

# ⚠️ Note on Backend Server
If you're searching for a recipe using an ingredient but no results appear, it's likely because the backend server is temporarily inactive due to free hosting limitations.

To reactivate it, simply open the following link in your browser:
👉 [https://mern-backend-us5i.onrender.com]

This will wake the backend server, and you can retry your request after a few seconds.
